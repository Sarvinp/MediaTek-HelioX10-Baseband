## Synthesis of R26–R31 (the complete picture)
The RIL's SIM-init is EVENT-DRIVEN:
  modem URC (+EIND:2) → RIL re-polls → GET_SIM_STATUS → APPSTATE...
Everything modem-side that we can force (PHB start, PHB finish,
+EIND:64/128) has been forced/proven. The one missing push is
**+EIND: 2** — and fix6's finish path prints it only if
  a) the URC-enable gate ([ctx+0x78] bit2) is set — the RIL must
     have requested EIND notifications (AT+EIND or +CMER style), AND
  b) the finish_rind actually runs with the gate satisfied.
fix5 (gate-nop on finish_rind at 0x3a1fb6) was tested WITHOUT fix6
present, so the two have never been combined.
