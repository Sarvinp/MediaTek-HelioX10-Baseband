## Remaining gap
L4C never SENDS the session-opening requests (verify_pin / app_start /
security_req). The L4C session state byte 0x569 never reaches the
value that triggers them. l4c_sim_security_check's decision depends on
r4 struct = result of l4c_check_sim_status (the raw SIM status from
SIM task). The status struct fields come from... the SIM task's
status CNF - which we know is the prebuilt-lib weak point.
