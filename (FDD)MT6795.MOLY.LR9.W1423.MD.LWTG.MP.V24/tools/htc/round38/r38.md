# Round 38 — T=0 Loop Read in Source; Probe Confirms External Reads Enter It (modem-ver-38)

## Source-level analysis (driver/devdrv/usim/src/ — the COMPILED copy)
- Build compiles driver/devdrv/usim/src/ (via make/module/driver/devdrv/usim.mak)
  — NOT driver/storage/sim/src/ (older duplicate; files differ!)
- L1sim_Cmd_Layer_MTK (line 4499, binary 0x10D5D5, 1076 bytes):
  the T=0 status-word engine. Structure:

    for(;;) {
      error?           -> return FAIL
      sw1==0x61/warn   -> GET RESPONSE (sw2 or rest-of-buffer), loop continues
      6C               -> resend cmd with sw2 length, loop continues
      case4 warns      -> GET RESPONSE len 0, loop continues
      else             -> command complete, return
    }

  **The loop has NO iteration cap.** Card answering 61xx forever = spin.
  Each L1sim_Cmd blocks on card -> MD sluggish not instantly dead ->
  watchdog eventually freezes (R37 dump pattern).

## Binary verification (matches source)
- Loop head 0x10D680, back-edge 0x10D744, 61xx cmp @0x10D74C,
  6Cxx cmp @0x10D7B2 — decoded from our ELF, structure identical.
- sim_al_read_record -> Sim_Cmd_All -> sim_driver_cmd_api -> driver
  table -> L1sim_Cmd_All -> L1sim_Cmd_MTK -> (T=0) L1sim_Cmd_Layer_MTK

## Probe result (fix6clean base, verified)
UDF at loop head 0x10D680: **CRASHED = REACHED** (LR 0x10D65B =
initial L1sim_Cmd return). External reads DO enter the T=0 loop.
Combined with R37 (freeze dump at AL return path, 8 identical BL
frames): the hang is INSIDE this loop for external reads.

## Working theory (final form)
Card answers external reads with endless 61xx (or the 6C resend
path ping-pongs) -> unbounded loop never exits -> no return to AL
-> no CNF, no timeout, PHB retries x4, SIM stuck NOT_READY.
Startup ICCID read (binary, small) exits the loop normally.

## Fix design (ver-39): cap the loop
Source fix in driver/devdrv/usim/src/icc_switchControl_mtk_0.c:
    kal_uint32 loop_guard = 0;
    for(;;) {
        if (++loop_guard > 32) { status = SIM_SW_STATUS_FAIL; return status; }
        ...
    }
Then REBUILD modem natively (driver is compiled from source!) and
flash the rebuilt image — first true source-level fix. Alternative
fallback: binary patch of the loop (count reg + branch), harder.
