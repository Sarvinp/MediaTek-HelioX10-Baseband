## THE SPLIT (R33-R36, now logically complete)
RUNS  = everything arriving via msg_receive_extq (external requests)
SILENT= everything that must travel msg_receive_intq (AL completions,
        timer expiry, error INDs)
=> The SIM task's INTERNAL queue delivery is dead. Watchdog starts
   but its expiry never re-enters the task loop; AL completions
   never re-enter; error INDs never re-enter. Externally-posted
   requests flow fine.
=> This is precisely the [SIM Q] instrumentation site in stock's
   HTC patch (queue find/pop/put, pools @ stock 0x528xxx, mapped R28).
   HTC patched the internal-queue machinery — strongest evidence yet
   that stock NEEDED that patch for this exact reason.

## Why reads differ (ICCID vs external)
Internal startup reads complete because usim_startup_read issues
them synchronously/inline in the same task context (no intq hop for
their completion dispatch — direct callback flow). External reads
require posting completion to intq → dead → hang forever, no
timeout (timer expiry also intq → also lost).
