## Synthesis (R33-R35 complete)
ALIVE: card, HISR/RX, ATR/t1end, select/select_aid/status/read_binary,
       timer-start/poll machinery, req handlers (generic+file_info),
       UICC detection, startup reads (ICCID via AL completes internally)
DEAD:  CNF send to ANY external requester — generic read CNF (1216),
       IMSI CNF, PHB IO CNF, security CNF; NO timeout error either.
=> Reads issued for EXTERNAL requesters hang forever inside the SIM
   task between AL completion and CNF build/send. Reads issued
   INTERNALLY (startup/ICCID) complete. Pattern = per-op context
   (peer/ilm ptr) not carried into the completion path, or the
   completion callback registration (per-request) is broken.
