## Unified theory (R33-R37 final)
External reads (PHB records, L4C IMSI...) enter the sync AL layer
and never come back: no CNF (handler can't send what it never got),
no timeout (sim_error_handler's timer expiry path equally stuck
behind the hang), PHB retries ×4 (+EIND:32 x4) then stops.
Internal startup reads (binary, ICCID) complete because binary path
works / runs in startup context.
=> BUG: infinite retry/loop inside sim_al_read_record (record path)
   for external requesters. Possibly card protocol (T=0) handling
