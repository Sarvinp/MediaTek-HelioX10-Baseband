## What this means
The RIL's PIN query (AT+EPINC) is answered from CACHED context
(l4csmu_get_chv_info_status just memcpy's from [smu_ctx+0xB4/+0x28]).
The LIVE security exchange — L4C sending MSG_ID_L4CSMU_SECURITY_REQ
(1619) to SMU, SMU querying the SIM, confirmation flowing back —
NEVER HAPPENS. Without it: no PIN state, no security_cnf, no
l4c_reset_sub_modules, no PHB startup, no +EIND: 2, no READY.
